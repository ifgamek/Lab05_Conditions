Изучили схему работы if, switch,? , || , ! , Parse, &&.
```csharp
using System;

class Program
{
    static void Main()
    {
        int sum = 0;

        for (int i = 0; i < 3; i++)
        {
            int a = int.Parse(Console.ReadLine());
            if (a > 0)
                sum += a;
        }

        Console.WriteLine(sum);
    }
}
```

| Конструкция | Когда использовать | Пример |
|---|---|---|
| `if` / `else` | Общее ветвление, сложные условия | `if (x > 0) { ... } else { ... }` |
| `else if` | Несколько взаимоисключающих вариантов | `if (x > 0) { ... } else if (x < 0) { ... } else { ... }` |
| `switch` / `case` | Сравнение одной переменной с конкретными значениями | `switch (day) { case 1: ... break; }` |
| Тернарный оператор `? :` | Выбор одного из двух значений в одну строку | `int max = a > b ? a : b;` |
| `&&` | Логическое И — оба условия должны быть истинны | `if (age >= 18 && hasPass) { ... }` |
| `\|\|` | Логическое ИЛИ — достаточно одного истинного условия | `if (x < 0 \|\| x > 100) { ... }` |
| `int.TryParse` | Безопасное преобразование строки в число | `if (int.TryParse(s, out int n)) { ... }` |
| `Random.Next(min, max)` | Генерация случайного числа в диапазоне (min, max) | `int r = rnd.Next(1, 7); // 1..6` |
